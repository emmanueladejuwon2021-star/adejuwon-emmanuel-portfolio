### Project Summaries & What They Do

1. **MenuCraft — QR Digital Menu Platform**
   - **What it does:** Contactless digital menu SaaS platform for dining establishments. Diners scan table QR codes to view live, mobile-optimized digital menus with no app installation required. Includes an administrative portal (`/admin`) for restaurant managers to update items, prices, photos, and allergen badges in real time.

2. **ShopVerse — Fast E-Commerce & Paystack Platform**
   - **What it does:** High-performance commercial e-commerce application equipped with a complete Paystack payment gateway, HMAC-SHA512 verified webhooks, server-side session persistence across serverless environments, CSRF token security, live product search API (`/api/search`), dynamic cart drawer API (`/api/cart`), and order tracking.

3. **Delta State Election Collation & Results Portal (Bincom)**
   - **What it does:** Civic data and electoral collation web portal for Delta State, Nigeria. Aggregates grassroots ballot counts across hundreds of polling units, displays statewide party standings and vote share charts, provides a complete Local Government Area (LGA) summary directory across 25 councils, and provides an authenticated return submission form for election field officers.

4. **PreMed Student Examination Portal**
   - **What it does:** Rigorous examination and study portal for university medical, dental, surgical, nursing, and healthcare students. Enforces strict matriculation code verification and department onboarding, providing practice test modules and automatic LaTeX formula parsing via KaTeX for complex biochemical and pharmacology formulas.

5. **SecureBank — Professional Banking Platform**
   - **What it does:** Full-featured digital banking interface featuring client onboarding, multi-factor authentication, interactive balance tracking, color-coded debit/credit transaction history logs, instant fund transfers, and interactive loan/mortgage calculators.

6. **TechPhone Pro — Flagship Smartphone Store**
   - **What it does:** Commercial mobile e-commerce platform equipped with a reactive multi-criteria filter sidebar (brand, storage, price min/max, star rating), a side-by-side device technical comparison matrix, customer review ratings, and an automated discount cart calculation engine.

7. **PhoneProSale — Premium Tech Retail Store**
   - **What it does:** Ultra-fast, lightweight gadget showcase store built with Vite and React. Features modern responsive product cards, accessory bundles, fluid hover transitions, and an optimized mobile shopping experience.

## 🛠️ Stack Architecture

- **Markup & Structure:** Semantic HTML5 (W3C & WCAG 2.1 AA Compliant)
- **Styling:** Tailwind CSS (Utility-first, responsive, and class-based dark mode)
- **Logic & Interactions:** Modern Vanilla JavaScript (ES6+ modular architecture)
- **Vector Icons:** Lucide Vector Icons
- **Celebration Effects:** Canvas Confetti
- **Build Tool (Optional):** Vite (for bundling or direct static hosting)
